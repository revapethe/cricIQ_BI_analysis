# Performance BI Analytics
### Sports Performance Intelligence | Power BI, Python & DAX

## Project Overview

Performance BI Analytics is an end-to-end sports analytics and business intelligence project designed to evaluate T20 cricket player performance through interactive Power BI dashboards.

The project transforms raw cricket match data into structured, analysis-ready datasets using Python and Pandas, followed by data modeling, DAX calculations, and interactive visualizations in Power BI.

The primary objective is to analyze batting and bowling performance, compare players across different playing roles, and support data-driven team selection through measurable performance indicators.

## Tech Stack

| Technology | Application |
|---|---|
| Power BI | Interactive dashboards and data visualization |
| Python | Data extraction, cleaning, and preprocessing |
| Pandas | Data manipulation and transformation |
| Power Query | Data cleaning and preparation |
| DAX | Calculated measures, columns, and KPIs |
| Jupyter Notebook | Data processing and exploration |
| JSON / CSV | Source data and structured datasets |

## Project Workflow

**1. Data Extraction and Preparation**

- Processed cricket match and player statistics from JSON datasets.
- Used Python and Pandas to extract, clean, and transform raw data.
- Converted nested JSON records into structured CSV datasets.
- Prepared batting, bowling, match, and player information for downstream analysis.

**2. Data Transformation and Modeling**

- Imported structured datasets into Power BI.
- Applied Power Query transformations to improve data consistency.
- Established relationships between datasets to support cross-table analysis.
- Created calculated columns and measures using DAX.

**3. Dashboard Development**

- Designed interactive dashboards for player-level and team-level performance analysis.
- Implemented slicers, filters, and navigation across player categories.
- Developed comparative visualizations to evaluate batting and bowling performance.
- Integrated key performance indicators to support analytical decision-making.

## Dashboard Features

### 1. Final XI Selection and Team Performance

An interactive team selection dashboard that enables users to select players and evaluate their combined performance.

Key features:
- Player selection through interactive slicers
- Team-level batting and bowling KPIs
- Player roles, batting styles, and bowling styles
- Batting average, strike rate, bowling economy, and dot-ball percentage
- Custom batting-order information

### 2. Batting Performance Analysis

Analyzes batting performance across different player roles, including power hitters, anchors, and finishers.

Key metrics:
- Total runs scored
- Batting average
- Batting strike rate
- Average balls faced
- Innings played
- Comparative batting performance trends

### 3. Bowling Performance Analysis

Evaluates specialist bowlers using performance indicators and comparative visualizations.

Key metrics:
- Total wickets
- Bowling average
- Bowling strike rate
- Economy rate
- Dot-ball percentage
- Balls bowled and runs conceded

### 4. All-Rounder Performance Analysis

Provides a combined assessment of batting and bowling contributions to evaluate player versatility.

Key features:
- Batting and bowling KPI comparisons
- Player-level performance filters
- Strike rate and economy analysis
- Comparative performance visualizations
